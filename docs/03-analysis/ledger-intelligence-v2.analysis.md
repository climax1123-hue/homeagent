## 반복 테스트 결과

첫 실행에서 충돌 fixture의 키워드 길이가 달라 의도한 동률이 아니었고, UI에 같은 카테고리명이 두 번 표시되며 기존 단일 요소 단언이 실패했다. fixture를 동일 등급으로 수정하고 UI 단언을 다중 요소 기준으로 변경했다. 실제 데이터 화면 검증에서는 소액 제안을 1만원 단위 올림하면 월평균보다 한도가 커지는 결함을 발견해 내림 방식과 상한 회귀 테스트로 보완했다.
