## 일치 항목

- 가족/개인 장부와 `household_id`·`owner_user_id` RLS
- 수입·지출·이체 등록 및 soft delete
- 정수 문자열/`bigint` 금액 계산과 월 요약 RPC
- 작성자·결제자 분리, 기본 카테고리와 결제수단
- 월/주 달력, 일별 합계와 선택일 상세
- Asia/Seoul 일자 입력과 UTC 저장
- 원자적 월 할부와 말일 보정
- 거래유형·결제수단·거래처/메모 필터
- 결제수단별 전체 잔액 RPC 표시
- 사용자 수입/지출 카테고리 추가
- PC/모바일 반응형 UI와 44px 주요 입력

## 잔여 차이

| 구분                            | 상태                                        | 처리                      |
| ------------------------------- | ------------------------------------------- | ------------------------- |
| 거래 수정 화면                  | API method는 추가했으나 UI 연결은 후속 개선 | `ledger-editing`으로 분리 |
| 결제수단·카테고리 수정/비활성화 | 생성과 조회만 UI 제공                       | `ledger-settings`로 분리  |

두 항목은 원장 저장 구조나 후속 `statement-import` 착수를 막지 않으며, 현재 사용자가 확인한 MVP 범위 밖의 관리 편의 기능으로 후속 backlog에 남긴다.
