# calendar-categories 구현 기록

## 구현 결과

- 일정 카드에 등록자 이름과 가족/개인 공개 범위를 표시했다.
- 등록자별 색상선과 동일한 구성원 색상 범례를 적용했다.
- `전체`, `가족 공유`, `내 일정`, `개인 일정`, 구성원별 필터를 추가했다.
- 일정 상세에 `Google Calendar에 이 일정 추가` 링크를 제공했다.
- 기존 가구 구성원 API와 RLS를 재사용해 DB 변경 없이 구현했다.

## Google Calendar 적용 범위

현재 구현은 선택한 일정 한 건을 Google Calendar 작성 화면으로 전달한다. 사용자가 Google 화면에서 최종 저장하며 OAuth 토큰은 필요 없다. 자동 변경 반영이나 Google 일정 가져오기는 포함하지 않는다.

## 검증

- 필터 및 Google URL 단위 테스트 4개 추가
- 웹 테스트 26개 통과
- TypeScript 및 프로덕션 빌드 통과
- 전체 lint 오류 0개(기존 auth Fast Refresh 경고 6개)
- 기본 5초 제한의 기존 UI 테스트는 느린 실행 환경에서 간헐적으로 timeout되어 20초 제한으로 재실행 후 모두 통과
