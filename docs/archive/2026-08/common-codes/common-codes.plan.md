# common-codes - Plan

> Version: 1.0.0 | Date: 2026-08-27 | Status: Approved

## 목표

- 가계부에 종속된 코드 관리를 가족 공간 전체의 공통코드 관리로 분리한다.
- 활성 가족 구성원은 코드 라벨을 조회하고, 가족 관리자만 확장형 코드 그룹을 변경한다.
- 역할·회원상태·공개범위·거래유형처럼 권한 또는 계산을 결정하는 코드는 중앙 등록하되 잠금 처리한다.
- 화면의 선택지는 공통코드 API를 통해 제공하고 하드코딩된 표시 라벨을 단계적으로 제거한다.

## 범위

- 공통코드 그룹: 결제수단 유형, 가족 역할, 구성원 상태, 일정 공개범위, 반복 주기, 일정 색상, 거래 유형, 장부 공개범위
- 관리자 전용 `/app/common-codes` 화면
- 결제수단 유형의 추가·라벨·정렬·활성 상태 관리
- 잠금 시스템 코드의 조회 및 변경 차단
- 가족 공간별 데이터 격리와 RLS

## 완료 조건

- 공통코드가 가계부 메뉴가 아닌 관리자 메뉴에서 관리된다.
- 일반 구성원과 다른 가족 공간 사용자는 코드를 변경할 수 없다.
- 잠금 그룹은 관리자도 구조를 변경할 수 없다.
- 가계부의 결제수단 유형 콤보는 중앙 공통코드를 사용한다.
- 신규 및 기존 장부에 기본 결제수단 5종이 표시된다.
