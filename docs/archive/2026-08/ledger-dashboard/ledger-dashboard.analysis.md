- 월별 차트는 외부 차트 패키지 대신 CSS 기반 막대로 구현했다. 번들 추가 없이 설계 의도를 충족한다.
- 로컬 Docker 장애로 신규 pgTAP 파일의 실제 실행은 보류했다. 동일 migration은 Supabase 클라우드에서 정상 적용되어 SQL 파싱과 생성이 검증됐다.
- 브라우저의 현재 로그인 계정에 활성 가족 공간이 없어 실데이터 화면 진입은 차단됐다. 390px/PC 레이아웃은 반응형 CSS와 컴포넌트 테스트로 검증했다.
