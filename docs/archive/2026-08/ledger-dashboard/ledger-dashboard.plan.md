# Ledger Dashboard Plan

## 목적

가족 또는 개인 장부의 수입·지출을 여러 관점에서 비교하여 소비 패턴과 개선 지점을 빠르게 파악하는 반응형 분석 화면을 제공한다.

## 범위

- 장부, 조회 기간(최근 1·3·6·12개월 및 직접 입력) 필터
- 총수입, 총지출, 순자산 증감, 저축률, 거래 수, 일평균 지출 KPI
- 직전 동일 기간 대비 증감
- 월별 수입·지출·순증감 추이
- 지출 카테고리, 결제수단, 결제자, 요일별 분석
- 일별 지출 추이, 상위 거래처, 반복 지출 후보
- 빈 데이터·로딩·오류 상태와 PC/모바일 반응형 UI
- 가족 장부와 개인 장부의 기존 접근 권한 유지

## 제외 범위

- 예산 자동 추천 및 AI 기반 월간 비용 제안
- 외부 금융 데이터 실시간 연동
- 사용자가 직접 만드는 커스텀 차트 빌더 및 파일 내보내기

## 성공 기준

- 사용자가 장부와 기간을 바꾸면 모든 지표가 같은 조건으로 갱신된다.
- 이체는 수입·지출 통계에서 제외되며 모든 금액은 bigint 기반 문자열로 처리된다.
- 직전 동일 기간과 비교한 증감률을 확인할 수 있다.
- 가족 장부는 활성 가족 구성원, 개인 장부는 소유자만 조회할 수 있다.
- 44px 터치 영역과 390px 모바일 폭에서 주요 분석을 사용할 수 있다.
- 관련 단위·UI·RLS 테스트와 `pnpm check`가 통과한다.

## 위험과 대응

- 대량 원장 조회: 브라우저 원본 집계 대신 권한 검증된 PostgreSQL RPC에서 집계한다.
- 금액 정밀도 손실: DB bigint/numeric을 text로 반환하고 클라이언트는 BigInt로 계산한다.
- 너무 많은 정보: 요약 KPI를 먼저 배치하고 상세 분석은 카드 단위로 분리한다.
- 개인 장부 노출: 기존 `private.can_read_ledger_book` 검사를 RPC 입구에서 강제한다.
