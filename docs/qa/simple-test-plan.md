# 우리집 웹사이트 간단 테스트 계획서

> **Summary**: 현재 구현된 핵심 기능을 자동 테스트와 사용자 확인으로 점검한다.
>
> **Author**: HomeWebSite Team
> **Created**: 2026-08-28
> **Status**: Review

---

## 1. 테스트 범위

- 로그인 및 가족 공간 접근
- 가족 구성원 권한
- 캘린더 일정 등록·조회
- 가족/개인 가계부와 거래·할부
- 공통코드 및 결제수단
- CSV/XLSX 명세 가져오기
- PC·모바일 기본 화면

## 3. 사용자 확인 체크리스트

- [ ] 로그인 후 가족 공간에 들어간다.
- [ ] 가족 구성원과 관리자 화면이 정상적으로 구분된다.
- [ ] 일정을 등록하고 캘린더에서 확인한다.
- [ ] 가족 일정과 개인 일정의 색상이 구분된다.
- [ ] 가계부 거래를 추가·삭제하고 달력 합계를 확인한다.
- [ ] 할부 거래가 월별로 나뉘어 생성된다.
- [ ] 관리자만 공통코드를 변경할 수 있다.
- [ ] 합성 CSV/XLSX 파일을 가져와 미리보기를 확인한다.
- [ ] 중복 후보와 오류 행이 구분되어 표시된다.
- [ ] PC와 휴대폰에서 버튼과 입력창을 사용할 수 있다.

## 4. 합격 기준

- 자동 테스트와 프로덕션 빌드가 통과한다.
- 권한이 없는 가족·개인 장부에 접근할 수 없다.
- 사용자가 위 체크리스트의 핵심 흐름을 완료할 수 있다.
- 실제 금융 명세 대신 개인정보를 제거한 테스트 파일을 사용한다.
