# 제품 의사결정 기록

## 웹 호스팅

### 확정

- React + Vite 웹 앱은 Vercel에 배포한다.
- GitHub `homeagent` 저장소와 연결해 기본 브랜치 push 시 production을 자동 배포한다.
- Pull Request 또는 개발 브랜치는 Vercel Preview Deployment로 확인한다.
- Supabase는 인증·PostgreSQL·RLS·Edge Functions 역할을 유지하며 Vercel로 이전하지 않는다.
- 개인 가족 프로젝트 단계에서는 Vercel Hobby 범위로 시작한다.

### 운영 원칙

- Vercel에는 `VITE_SUPABASE_URL`, publishable key 등 공개 가능한 브라우저 환경변수만 등록한다.
- Supabase `service_role`, Google OAuth client secret과 refresh token은 Vercel 프런트 환경변수에 넣지 않는다.
- 실제 production 배포 연결은 핵심 MVP의 외부 테스트를 시작할 때 수행한다.

## 가족 구성원 관리

### 확정

- 주 사용자는 가족 구성원이다.
- 최초 사용자는 관리자이며 최초 가정을 생성한다.
- MVP에서는 관리자가 아내의 개인 이메일 주소로 1회용 가입 경로를 보내고, 아내가 해당 링크에서 본인 계정을 활성화해 참여한다.
- 사용자가 사용하는 계정 ID와 로그인 ID는 이메일 주소다.
- DB 내부 관계에는 이메일이 아닌 변경 불가능한 UUID `user_id`를 사용한다.
- 가족 구성원의 승인, 상태 수정과 탈퇴 처리는 관리자만 수행한다.
- 일반 구성원은 다른 가족 구성원을 관리할 수 없다.
- 향후 Google 계정 사용자는 가입 요청을 보내고 관리자가 승인한다.
- Google 인증 성공과 가족 가입 승인은 별도 단계다.
- 탈퇴 처리된 사용자의 공유 데이터 접근은 즉시 차단한다.

### 임시 기본값

- 구성원 삭제는 이력 보존을 위해 상태 변경으로 처리한다.
- 마지막 관리자의 탈퇴 또는 권한 해제는 차단한다.
- 관리자는 다른 사용자의 비밀번호를 직접 만들지 않고 이메일 초대를 사용한다.

### 추후 결정

- 복수 관리자 허용 여부
- 관리자 계정 복구와 관리자 이전 방법
- 구성원의 자발적 탈퇴 요청 절차
- 탈퇴 후 재가입 정책
- Google 사용자가 가입할 가정을 찾는 방식

## 일정과 알림

### 확정

- 기본 일정 관리와 Google Calendar 연동을 제공한다.
- 월간, 주간과 목록 보기 및 일반·종일·반복 일정을 지원한다.
- 개인 일정과 가족 공유 일정을 구분한다.
- 다가오는 일정 알림과 독립적인 반복 생활 알림을 제공한다.
- 매일 아침 약 복용과 오늘 일정 요약 같은 반복 알림을 지원한다.
- Android와 iPhone을 하나의 반응형 웹/PWA 코드베이스로 지원한다.
- Google Calendar 일정은 Google 알림을 활용할 수 있게 한다.
- 우리집 전용 알림은 PWA Web Push를 사용한다.

### 플랫폼 제약

- iPhone Web Push는 iOS 16.4 이상 홈 화면 웹 앱을 기본 지원 경로로 한다.
- 모든 Push 알림은 사용자 권한 허용이 필요하다.
- Web Push는 OS와 네트워크 영향으로 정확한 시각과 100% 수신을 보장하지 않는다.
- 건강상 반드시 놓치면 안 되는 알림의 유일한 수단으로 Web Push를 사용하지 않는다.

### 추후 결정

- Google Calendar 양방향 동기화를 MVP에 포함할지 단계적으로 배포할지
- 약 복용 완료 확인과 미복용 재알림 기능
- 가족 공용 알림을 관리자가 강제로 설정할 수 있는 범위
- Push 외 이메일 알림을 보조 수단으로 제공할지
