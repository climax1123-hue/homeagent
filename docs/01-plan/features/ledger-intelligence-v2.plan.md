# 가계부 지능화 2차 - Plan

## 목적

은행·카드 명세의 자동 분류 오분류를 줄이고, 기존 대시보드 통계를 다음 달 행동 기준으로 바꾼다.

## 범위

- 전각 문자, 구두점, 보이지 않는 문자 정규화
- 우선순위·정확 일치·키워드 길이에 따른 결정적 규칙 평가
- 동률 규칙이 서로 다른 카테고리를 가리키면 자동 선택 중단
- 낮은 신뢰도의 짧은 영문 규칙은 사용자 확인 요구
- 최근 최대 3개월 월평균과 수입을 이용한 다음 달 지출 한도 제안
- 카테고리별 참고 한도와 지출 변화 점검 포인트

## 제외

- 외부 AI/금융 API, 금융 자문, 자동 결제 차단
- 사용자의 확인 없이 과거 원장 재분류
- 실제 은행 명세 또는 개인정보 fixture 커밋

## 성공 기준

- 규칙 배열 순서와 무관하게 동일한 분류 결과가 나온다.
- 동률 충돌과 낮은 신뢰도는 자동 카테고리 확정을 하지 않는다.
- 모든 금액 계산은 `BigInt` 정수 연산을 사용한다.
- 데이터가 3개월 미만이면 낮은 신뢰도를 명시한다.
- PC·모바일에서 제안 영역이 가로 스크롤 없이 표시된다.
- 전체 `pnpm check`가 통과한다.

## 위험과 대응

- 보수적 분류로 자동 추천률이 낮아질 수 있음: 추천 이유와 검토 필요 상태를 표시한다.
- 부분 월 데이터가 평균에 포함될 수 있음: 참고용임을 명시하고 추후 완결 월 기준 서버 집계로 확장한다.
- 제안을 금융 자문으로 오인할 수 있음: 최근 기록 기반 참고 한도로 표현한다.
