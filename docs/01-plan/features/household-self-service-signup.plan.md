# 신규 가족 관리자 가입 계획

## 목표

새 사용자가 이메일 인증 후 독립된 가족 공간을 만들고 그 공간의 최초 관리자가 될 수 있게 한다.

## 범위

- 로그인 화면의 새 가족 공간 만들기 진입점
- 이메일·비밀번호 가입과 이메일 확인
- 미배정 사용자의 가족 공간/표시 이름 입력
- 가정과 관리자 관계의 원자적 생성
- 기존 활성 가족 보유자의 중복 생성 차단

## 완료 조건

- 새 가족의 데이터는 기존 가족과 `household_id` 및 RLS로 격리된다.
- 인증되지 않은 계정과 익명 사용자는 가족 공간을 만들 수 없다.
- 한 계정은 하나의 현재 가족 공간만 가질 수 있다.
- 테스트, 타입 검사와 프로덕션 빌드가 통과한다.
