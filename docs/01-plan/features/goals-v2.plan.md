# 목표관리 고도화 - Plan

## 목적

목표를 단순 기록하는 수준에서 벗어나, 사용자가 우선순위와 마감 상태를 파악하고 카드에서 즉시 진행 상황을 갱신할 수 있게 한다.

## 범위

- 높음·보통·낮음 우선순위 저장 및 정렬
- 진행 중·완료·평균 진행률 요약
- 목표일의 남은 날과 지연 상태 표시
- 카드에서 진행률 10% 증가 및 완료 처리
- 기존 가족/개인 공개와 작성자·관리자 권한 유지

## 성공 기준

- 90% 목표의 `+10%`는 진행률 100과 완료 상태를 함께 저장한다.
- 완료 항목보다 진행 항목이 먼저, 같은 상태에서는 우선순위와 목표일로 정렬한다.
- 모바일에서 요약과 카드가 한 열로 표시되고 모든 버튼이 44px 이상이다.
- 전체 검사와 빌드가 통과한다.
