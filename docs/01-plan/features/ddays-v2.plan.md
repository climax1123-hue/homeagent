# 디데이 고도화 - Plan

## 목적

디데이가 많아져도 중요한 날을 빠르게 찾고, 가까운 일정과 반복 기념일의 의미를 한눈에 파악할 수 있게 한다.

## 범위

- 생일·기념일·여행·행사·기타 분류
- 분류 필터와 중요한 날 상단 고정
- 7일·30일 이내 및 중요 항목 요약
- 반복 항목의 도래 회차 표시
- 실제 존재하는 달력 날짜 검증

## 성공 기준

- 중요 항목은 날짜와 관계없이 목록 상단에 표시된다.
- 반복 항목은 원래 연도부터 현재 도래일까지 회차가 계산된다.
- 2월 30일 같은 날짜는 클라이언트에서 거부한다.
- 기존 공개 범위와 RLS가 유지되고 전체 검사가 통과한다.
