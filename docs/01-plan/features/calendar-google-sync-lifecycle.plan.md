# Google Calendar 동기화 마무리 계획

## 목표

사용자가 선택하면 본인 소유 일정의 생성·수정을 Google 기본 캘린더에 자동 반영하고, 연결된 일정 삭제·상태 확인·실패 재시도를 지원한다.

## 범위

- 사용자별 자동 동기화 설정
- 로컬 일정 생성·수정 후 자동 Google upsert
- 연결된 로컬 일정 삭제 전 Google 일정 삭제
- 일정별 `미동기화/동기화 중/완료/실패` 표시
- 실패한 생성·수정·삭제의 수동 재시도

## 제외

- Google에서 우리집으로 가져오기
- Google에서 변경한 일정의 역방향 반영
- 가족 구성원이 소유한 일정을 다른 구성원이 Google에 쓰기

## 완료 조건

- 로컬 저장은 Google 장애 때문에 롤백되지 않는다.
- 실패 상태와 오류가 DB에 남고 동일 버튼으로 재시도할 수 있다.
- Google 삭제 실패 시 로컬 일정을 보존하여 재시도할 수 있다.
- 토큰과 service role은 브라우저에 노출하지 않는다.
- 테스트와 `pnpm check`가 통과한다.
