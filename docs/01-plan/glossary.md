# 우리집 웹사이트 용어집

| 코드 용어          | 화면 용어    | 정의                                                                 |
| ------------------ | ------------ | -------------------------------------------------------------------- |
| Household          | 가족 공간    | 구성원과 공유 데이터가 속하는 최상위 보안 경계                       |
| Household Member   | 가족 구성원  | 가족 공간에 가입한 사용자와 역할·상태 정보                           |
| Admin              | 관리자       | 초대, 구성원 상태, 확장형 공통코드를 관리하는 구성원                 |
| Family Visibility  | 가족 공유    | 활성 가족 구성원에게 공개되는 일정 또는 장부                         |
| Private Visibility | 개인         | 소유자 본인에게만 공개되는 일정 또는 장부                            |
| Ledger Book        | 장부         | 결제수단·카테고리·거래를 묶는 가계부 단위                            |
| Ledger Account     | 결제수단     | 현금, 은행 계좌, 카드처럼 거래 금액이 귀속되는 수단                  |
| Transaction        | 거래         | 수입, 지출 또는 결제수단 간 이체 원장 행                             |
| Payer              | 결제자       | 거래를 입력한 작성자와 별개인 실제 결제/귀속 구성원                  |
| Installment Group  | 할부 묶음    | 하나의 원금을 여러 월별 거래로 연결하는 UUID                         |
| Calendar Event     | 일정         | 기간, 공개범위, 반복 규칙을 가진 일정 원본                           |
| Occurrence         | 일정 회차    | 반복 원본에서 화면상 계산된 개별 발생 건                             |
| Exception          | 일정 예외    | 특정 반복 회차의 취소 또는 내용 덮어쓰기                             |
| Common Code        | 공통코드     | 시스템 선택값의 코드·표시명·순서·활성 상태 정의                      |
| RLS                | 행 수준 보안 | 로그인 사용자별로 DB 행 조회·변경을 제한하는 PostgreSQL 정책         |
| RPC                | DB 함수 호출 | 여러 행을 원자적으로 처리하거나 요약을 계산하는 PostgreSQL 함수 호출 |
| Soft Delete        | 논리 삭제    | 행을 물리 삭제하지 않고 `deleted_at`으로 숨기는 방식                 |
