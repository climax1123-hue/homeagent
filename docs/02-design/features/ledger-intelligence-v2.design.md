# 가계부 지능화 2차 - Design

## 분류 엔진

`normalizeClassificationText`는 NFKC 정규화 후 제어·제로폭 문자와 문장부호를 공백으로 통일한다.

일치 후보 정렬 순서는 다음과 같다.

1. 관리자가 지정한 낮은 `priority` 값
2. `exact` 우선
3. 정규화된 키워드 길이가 긴 규칙
4. 거래처 일치 우선
5. 생성 시각과 ID

최상위 두 후보의 1~4 조건이 같고 카테고리가 다르면 충돌로 간주해 `null`을 반환한다. 짧은 영문 포함 규칙은 `low` 신뢰도와 `requiresReview=true`를 반환하며 가져오기 화면은 카테고리를 자동 선택하지 않는다.

## 비용 제안

`buildLedgerMonthlyRecommendation`은 대시보드 JSON만 입력받는 순수 함수다.

- 기준 지출: 최근 최대 3개월 지출 정수 평균
- 지출 기준 한도: 기준 지출의 95%
- 수입 기준 한도: 평균 수입의 80%
- 최종 제안: 두 값 중 작은 금액을 1만원 단위 내림
- 카테고리 한도: 현재 2, 이전 1 가중 평균의 95%를 1만원 단위 내림
- 신뢰도: 3개월 이상 높음, 2개월 보통, 그 미만 낮음

점검 포인트는 전체 지출 10% 이상 증가, 카테고리 20% 이상 증가, 양수 순증감, 데이터 부족을 설명 가능한 문장으로 생성한다.

- 유니코드·구두점·제로폭 정규화
