# 디데이 고도화 - Design

## 데이터

- `category`: `birthday|anniversary|trip|event|other`, 기본 `other`
- `is_pinned`: boolean, 기본 false

기존 RLS 정책이 동일 행의 새 컬럼에도 적용된다.

## 로직

- 정렬: 중요 표시 우선 → 실제 도래일까지 남은 일수
- 요약: 서울 기준 오늘로부터 0~~7일, 0~~30일 범위
- 반복 회차: `도래 연도 - 최초 연도 + 1`
- 날짜 검증: 정규식뿐 아니라 UTC 달력 구성 결과가 입력 연·월·일과 같은지 확인

## UI·테스트

요약 카드, 종류 선택 필터, 종류·중요 배지, 중요 토글과 반복 회차를 표시한다. 반복 연도, 윤일, 날짜 유효성, 중요 토글과 모바일 한 열 배치를 검증한다.
