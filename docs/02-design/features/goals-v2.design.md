# 목표관리 고도화 - Design

## 데이터

`goals.priority text not null default 'medium'`을 추가하며 `low|medium|high` 체크 제약조건을 둔다. 기존 행은 `medium`으로 안전하게 이관한다. 기존 RLS가 행 전체에 적용되므로 권한 경계는 변하지 않는다.

## 로직

- 정렬: 미완료 우선 → 우선순위 → 목표일
- 마감: 서울 기준 오늘과 `date`를 달력 일수로 비교
- 빠른 진행: 10% 증가하되 100을 넘지 않으며, 100이면 상태도 `completed`
- 완료 버튼: 진행률 100과 상태 완료를 원자적인 한 번의 update로 전달

## UI·테스트

상단 3개 요약 카드, 우선순위 배지, 마감 문구, 빠른 실행 버튼을 추가한다. 생성 기본 우선순위와 빠른 완료, 권한별 버튼 노출, 반응형 배치를 검증한다.
