# 일정 관리

## 사용자 목표

가족 구성원은 개인 일정과 가족 공유 일정을 PC, Android와 iPhone에서 확인하고 관리한다. Google Calendar를 사용하는 구성원은 선택한 캘린더를 연결해 일정을 동기화할 수 있다.

## 제품 목표

Google Calendar의 모든 기능을 복제하는 것이 아니라 가족 생활에 자주 필요한 일정 기능을 우선 제공하고, Google Calendar 연동 시 기존 일정과 알림 생태계를 활용한다.

## MVP 포함 범위

- 월간, 주간과 일정 목록 보기
- 오늘 일정과 다가오는 일정 표시
- 일반 일정과 종일 일정 생성·조회·수정·삭제
- 일정 제목, 설명, 장소, 시작·종료, 시간대와 색상
- 개인 일정과 가족 공유 일정
- 매일, 매주, 매월, 매년 반복 일정
- 반복 종료일 또는 반복 횟수
- 일정 시작 전 알림 시간 설정
- 가족 구성원별 알림 설정
- Google 계정과 Calendar 연결
- 사용자가 연동할 Google Calendar 선택
- 초기 동기화와 변경분 동기화
- 동기화 상태와 마지막 성공 시각 표시
- PC, Android와 iPhone 반응형 화면

## 단계적 확장 범위

- 참석자 초대와 참석 응답
- 반복 일정의 특정 회차만 수정
- 여러 시간대 표시
- 일정 검색과 고급 필터
- 캘린더별 공유 권한
- 첨부파일과 화상회의 링크
- Google Calendar 양방향 충돌 해결 UI

## 초기 제외 범위

- Google Calendar의 모든 고급 기능 완전 복제
- 회의실과 조직 자원 예약
- 네이티브 iOS 또는 Android 앱
- SMS 및 전화 알림
- 알림 전달 시각의 절대적 보장

## 캘린더 종류

### 가족 캘린더

- 가정 구성원에게 공유되는 기본 캘린더
- `active` 구성원이 조회하고 일정을 생성할 수 있음
- 일정 작성자 또는 관리자가 일정을 수정·삭제할 수 있음

### 개인 캘린더

- 작성자만 조회할 수 있는 일정
- 가족 홈 화면에는 제목과 세부 내용을 노출하지 않음
- 사용자가 원하면 `busy` 상태만 공유하는 기능은 후속 단계에서 검토

### Google 연결 캘린더

- 사용자가 Google 계정에서 선택한 캘린더
- 캘린더별로 `읽기 전용` 또는 `양방향` 동기화 모드 설정
- 연결을 해제해도 우리집에서 직접 생성한 로컬 일정은 보존

## 일정 사용자 흐름

### 일정 생성

1. 사용자가 날짜 또는 `일정 추가`를 선택한다.
2. 제목과 시작·종료 시간을 입력한다.
3. 개인 또는 가족 공유 범위를 선택한다.
4. 필요하면 반복 규칙과 알림 시간을 설정한다.
5. Google 연결 캘린더에 저장할지 선택한다.
6. 시스템이 일정을 저장하고 동기화 상태를 표시한다.

### 일정 수정

1. 사용자가 수정할 일정을 선택한다.
2. 반복 일정이면 `이번 일정만`, `이후 일정`, `전체 반복 일정` 중 범위를 선택한다.
3. 시스템은 권한을 확인한 뒤 변경한다.
4. Google 일정이면 변경을 동기화하고 성공 또는 실패 상태를 표시한다.

### 일정 삭제

1. 사용자가 삭제 범위를 선택한다.
2. 시스템은 작성자 또는 관리자 권한을 확인한다.
3. Google 일정이면 외부 삭제 정책을 확인한 뒤 반영한다.
4. 동기화 재시도 가능성을 위해 삭제 표식을 일정 기간 보존한다.

## 반복 규칙

- 매일
- 평일
- 특정 요일 조합
- 매주
- 매월 특정 날짜
- 매월 특정 주와 요일
- 매년
- 종료일 없음, 특정 날짜 종료 또는 횟수 종료

반복 규칙은 iCalendar `RRULE`과 호환되는 형태로 저장해 Google Calendar와의 변환 손실을 줄인다.

## 권한 규칙

- `active` 가족 구성원만 가족 캘린더를 조회한다.
- 개인 일정은 작성자만 조회·수정·삭제한다.
- 가족 일정은 작성자 또는 관리자만 수정·삭제한다.
- Google Calendar token은 해당 Google 계정을 연결한 사용자에게 귀속한다.
- 다른 가족 구성원이 연결한 Google 개인 캘린더에는 접근할 수 없다.
- Google 연결 여부와 무관하게 모든 API와 RLS에서 `household_id`를 검증한다.

## Google Calendar 연동

### 연결

1. 사용자가 설정에서 Google Calendar 연결을 선택한다.
2. 시스템은 Calendar 기능에 필요한 최소 OAuth scope를 요청한다.
3. 사용자가 연결할 Google Calendar를 명시적으로 선택한다.
4. 시스템은 선택한 캘린더별 동기화 모드를 저장한다.

Google 로그인과 Google Calendar 연결은 별도 동의 절차다. Google 계정으로 로그인했더라도 Calendar 접근 권한을 자동 요청하지 않는다.

### 동기화 단계

1. 1차: Google에서 우리집으로 읽기 동기화
2. 2차: 우리집에서 생성한 일정을 선택한 Google Calendar에 쓰기
3. 3차: 양방향 변경, 삭제와 반복 일정 예외 처리

초기 전체 동기화 후 Google `syncToken`을 저장하고 이후 변경분만 가져온다. token이 만료되어 `410 Gone`이 반환되면 전체 재동기화를 수행한다.

### 충돌 처리

- 로컬과 Google에서 동시에 수정된 일정을 자동으로 조용히 덮어쓰지 않는다.
- 외부 ID, 외부 수정 시각과 로컬 수정 시각을 보존한다.
- MVP에서는 마지막 수정 우선 정책과 충돌 로그를 사용한다.
- 사용자가 선택해야 하는 충돌 UI는 양방향 동기화 고도화 단계에서 제공한다.

## 오류 및 예외

- 종료 시각이 시작 시각보다 빠름
- 잘못된 시간대 또는 존재하지 않는 로컬 시각
- 반복 규칙을 해석할 수 없음
- 권한 없는 일정 수정·삭제
- Google OAuth 동의 취소 또는 token 만료
- Google Calendar가 삭제되거나 접근 권한이 제거됨
- 동기화 중 동일 일정 중복 생성
- 네트워크 장애로 Google 변경 반영 실패
- Google과 로컬에서 동시에 수정됨

Google 동기화 실패가 로컬 일정 기능 전체를 막지 않도록 실패 상태를 저장하고 재시도한다.

## 인수 조건

- PC와 모바일에서 월간, 주간과 목록 보기를 사용할 수 있다.
- 개인 일정과 가족 일정을 구분해 생성할 수 있다.
- 권한 없는 구성원에게 개인 일정 내용이 노출되지 않는다.
- 종일 일정과 반복 일정을 생성·수정·삭제할 수 있다.
- 일정 시작 전 여러 알림 시점을 설정할 수 있다.
- Google Calendar 연결과 해제가 가능하다.
- 선택한 Google Calendar의 일정을 중복 없이 가져온다.
- 동기화 실패와 마지막 성공 시각을 확인할 수 있다.
- Google 연결 장애 중에도 로컬 일정을 조회·작성할 수 있다.

- 다른 가정 일정 접근 차단
