# 홈 통합 대시보드

## 사용자 목표

가족 구성원은 로그인 직후 일정, 가계부, 디데이와 목표의 핵심 정보를 한 화면에서 확인하고 자주 쓰는 메뉴로 이동한다.

## MVP 범위

- 오늘부터 14일 이내의 다가오는 일정
- 기본 가계부의 이번 달 수입·지출·잔액
- 가까운 디데이
- 진행 중인 목표와 진행률
- 일정·거래·목표·디데이 바로가기
- 구성원별 카드 순서 저장
- PC 드래그 앤 드롭과 모바일 위·아래 이동
- 로딩·일부 기능 오류 상태와 PC·모바일 반응형 화면

## 권한 규칙

- 기존 기능의 RLS 결과만 대시보드에 표시한다.
- 다른 구성원의 개인 일정·가계부·목표·디데이는 표시하지 않는다.
- 배치 설정은 활성 가족 구성원이 본인 설정만 조회·변경한다.

## 인수 조건

- 일부 기능 데이터가 없거나 조회에 실패해도 나머지 대시보드를 사용할 수 있다.
- 금액은 정수 문자열로 전달하고 부동소수점 계산을 하지 않는다.
- 카드 순서를 저장하면 같은 구성원이 다시 로그인해도 유지된다.
- 모바일에서 가로 스크롤 없이 사용하며 주요 터치 영역은 44px 이상이다.
