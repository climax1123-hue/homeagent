# 디데이 관리

## 사용자 목표

가족 구성원은 생일, 기념일, 여행 등 중요한 날짜를 등록하고 남은 날짜를 한눈에 확인한다.

## MVP 범위

- 가족/개인 공개범위
- 제목, 기준일, 메모, 매년 반복 여부
- 디데이 등록·조회·수정·삭제
- 미래 `D-N`, 당일 `D-DAY`, 지난 날짜 `D+N` 표시
- 매년 반복 항목은 다음 도래일을 기준으로 계산
- 가족 항목은 모든 활성 구성원이 조회하고 작성자 또는 관리자가 변경
- 개인 항목은 작성자만 조회·변경
- PC·모바일 반응형 화면과 성공·오류 팝업

## 인수 조건

- 날짜는 시간대 변환 없는 달력 날짜로 저장한다.
- 매년 반복 기념일이 지났으면 다음 해 날짜를 사용한다.
- 다른 구성원의 개인 디데이는 조회할 수 없다.
- 가족 디데이를 일반 구성원이 작성할 수 있고 작성자 또는 관리자가 수정·삭제할 수 있다.
