# 알림 관리

## 사용자 목표

가족 구성원은 다가오는 일정과 매일 아침 약 복용처럼 반복되는 생활 알림을 원하는 기기에서 받을 수 있다.

## 결론

웹에서도 Push 알림을 구현할 수 있으므로 기능을 제외하지 않는다. 다만 기기와 브라우저별 조건이 다르며 전달 시각을 절대적으로 보장할 수 없으므로 다음 두 경로를 함께 사용한다.

1. Google Calendar에 동기화된 일정은 Google Calendar 알림을 우선 활용한다.
2. 우리집 전용 일정과 생활 알림은 PWA Web Push를 사용한다.

## 플랫폼 지원 정책

### Android

- 지원 브라우저에서 Web Push 구독 가능
- 사용자가 알림 권한을 허용해야 함
- 브라우저 또는 설치한 PWA의 알림 설정이 켜져 있어야 함

### iPhone

- iOS 16.4 이상을 지원 대상으로 함
- Safari에서 사이트를 홈 화면에 추가한 웹 앱(PWA)에서 Web Push 사용
- 홈 화면 앱을 실행한 뒤 사용자가 알림 권한을 직접 허용해야 함
- Safari 탭으로 접속만 한 상태의 동작을 기본 지원 경로로 간주하지 않음

### PC

- 지원 브라우저에서 Web Push 사용
- 브라우저와 운영체제 알림 권한 필요

## 제품 내 안내

- 기기별 `알림 사용 가능`, `설치 필요`, `권한 차단`, `구독 만료` 상태 표시
- iPhone에는 홈 화면 추가 방법을 단계별로 안내
- 권한 요청은 첫 방문 즉시 띄우지 않고 사용자가 `알림 켜기`를 선택한 뒤 요청
- 테스트 알림 전송 기능 제공
- 마지막 성공·실패 시각과 실패 원인을 알림 설정 화면에 표시

## 알림 종류

### 일정 알림

- 일정 시작 시각
- 5분, 10분, 30분, 1시간, 1일 전
- 사용자 지정 시간
- 하나의 일정에 여러 알림 시점
- 종일 일정의 기본 알림 시각 설정

### 반복 생활 알림

- 예: 매일 오전 8시 약 복용
- 매일, 평일, 특정 요일, 매월과 사용자 지정 반복
- 시작일과 종료일
- 사용자 시간대
- 일시 중지와 다시 시작
- 특정 날짜 한 번 건너뛰기
- 알림 대상 가족 구성원 선택

### 아침 요약 알림

- 사용자가 지정한 아침 시각에 오늘 일정 요약
- 일정이 없을 때 알림을 보낼지 선택
- 개인 일정 제목은 해당 사용자에게만 포함

## 알림 데이터 모델 방향

- `notification_rules`: 일정 또는 독립 생활 알림의 규칙
- `notification_targets`: 알림을 받을 구성원
- `push_subscriptions`: 사용자와 기기별 Web Push 구독
- `notification_deliveries`: 예약, 전송, 실패와 재시도 이력
- `notification_preferences`: 사용자별 기본 시간과 알림 종류 설정

한 사용자가 PC, Android와 iPhone을 모두 등록할 수 있으므로 Push 구독은 사용자당 하나가 아니라 기기·브라우저별로 저장한다.

## 처리 흐름

1. 사용자가 알림 규칙을 생성한다.
2. 서버가 다음 발송 시각을 UTC로 계산해 저장한다.
3. Supabase Cron이 정기적으로 발송 대상 작업을 조회한다.
4. Edge Function이 사용자별 활성 Push 구독으로 알림을 전송한다.
5. 성공, 실패와 재시도 결과를 기록한다.
6. 반복 규칙이면 다음 발송 시각을 계산한다.

## 전달 보장 수준

- Web Push는 브라우저가 닫혀 있어도 서비스 워커를 통해 수신할 수 있다.
- 사용자가 권한을 끄거나 PWA를 삭제하면 전달되지 않는다.
- OS 절전, 네트워크, 브라우저 정책에 따라 지연될 수 있다.
- 정확한 초 단위 전송과 100% 수신을 보장하지 않는다.
- 약 복용처럼 놓치면 건강상 위험한 알림의 유일한 수단으로 사용하지 않는다는 안내를 표시한다.

## 권한 규칙

- 알림 규칙 작성자와 대상 사용자만 개인 알림 내용을 조회한다.
- 가족 공용 알림은 관리자가 전체 대상자를 변경할 수 있다.
- 일반 구성원은 자신이 받을 알림을 끌 수 있다.
- 다른 사용자의 Push 구독 endpoint를 조회하거나 사용할 수 없다.
- Push endpoint와 암호화 키는 민감정보로 취급하고 로그에 기록하지 않는다.

## 오류 및 예외

- 사용자가 알림 권한을 거절함
- iPhone에서 PWA를 설치하지 않음
- Push 구독이 만료되거나 endpoint가 폐기됨
- 사용자 시간대가 변경됨
- 반복 규칙 변경 중 이미 발송 작업이 생성됨
- 같은 알림이 중복 발송됨
- Cron 또는 Edge Function 실행 실패
- Google Calendar와 우리집 양쪽에서 동일 일정 알림을 켜 중복 수신

Google과 우리집 알림을 동시에 사용할 경우 중복 가능성을 표시하고 사용자에게 기본 알림 경로를 선택하게 한다.

## 인수 조건

- 사용자가 기기별 알림 가능 상태를 확인할 수 있다.
- Android와 지원 PC 브라우저에서 Push 구독과 테스트 알림이 동작한다.
- iPhone PWA에서 Push 구독과 테스트 알림이 동작한다.
- 일정 시작 전 지정한 시간에 발송 작업이 생성된다.
- 매일 아침 약 복용 알림을 생성·일시 중지·재개·삭제할 수 있다.
- 매일 아침 오늘 일정 요약을 받을 수 있다.
- 동일 발송 작업이 재시도 중 중복 전송되지 않는다.
- 개인 알림 내용이 다른 가족 구성원에게 노출되지 않는다.
- 만료된 Push 구독을 비활성화한다.

## 필수 테스트

- 일정 상대시간 알림 계산
- 매일·요일별·월별 반복 알림 계산
- Asia/Seoul과 UTC 변환
- 일광절약시간을 사용하는 다른 시간대 테스트
- 중복 발송 방지 idempotency
- 실패 재시도와 최대 재시도 횟수
- 사용자별·기기별 Push 구독 격리
- 권한 거절과 구독 만료 처리
- Android Chrome 실제 기기 테스트
- iOS 16.4 이상 홈 화면 PWA 실제 기기 테스트
