# 운영 오류 관리

## 목적

실사용 중 화면에 표시된 오류를 가족 공간 단위로 기록하고 관리자가 발생 시점과 메뉴를 확인한다.

## 동작

- 오류 팝업이 표시될 때 사용자용 메시지, 현재 경로, 메뉴, 발생 시각을 기록한다.
- 입력값, 금융 상세, 이메일, 외부 서비스 원문 오류, 토큰은 기록하지 않는다.
- 관리자는 `더보기 > 오류 기록`에서 최근 100건을 확인하고 해결 여부를 변경한다.
- 일반 구성원은 오류를 기록할 수 있지만 목록을 조회하거나 수정할 수 없다.

## 권한

`app_error_logs.household_id`로 가족 공간을 격리한다. RLS는 활성 구성원의 본인 오류 등록과 활성 관리자의 조회·상태 변경만 허용한다.
