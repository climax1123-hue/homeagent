# 목표 관리

## 사용자 목표

가족 구성원은 개인 목표와 가족 공동 목표를 등록하고 진행률을 기록하며 완료 여부를 함께 확인한다.

## MVP 범위

- 가족/개인 공개범위
- 제목, 설명, 목표일, 진행률, 상태(진행 중·일시정지·완료)
- 목표 등록·조회·수정·삭제
- 전체·진행 중·완료 필터
- 우선순위(높음·보통·낮음)와 우선순위 기반 정렬
- 목표 요약, 마감 임박·지연 표시
- 카드에서 진행률 10% 증가 및 즉시 완료
- 가족 목표는 모든 활성 구성원이 조회하고 작성자 또는 관리자가 변경
- 개인 목표는 작성자만 조회·변경
- PC·모바일 반응형 화면과 성공·오류 팝업

## 인수 조건

- 진행률은 0~100 범위이며 완료 상태는 진행률 100으로 저장된다.
- 목표일이 없는 목표도 등록할 수 있다.
- 빠른 진행에서 100%에 도달하면 완료 상태로 함께 저장된다.
- 다른 구성원의 개인 목표는 조회할 수 없다.
- 가족 목표를 일반 구성원이 작성할 수 있고 작성자 또는 관리자가 수정·삭제할 수 있다.
